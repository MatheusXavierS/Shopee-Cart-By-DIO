# 🛒 Shopee Cart (Backend)

Projeto backend desenvolvido em **Node.js** com o objetivo de simular o funcionamento de um **carrinho de compras**, inspirado no modelo da Shopee.  
O foco do projeto é **organização de código**, **boas práticas de backend** e **separação de responsabilidades**.

---

## 📌 Objetivo do Projeto

- Praticar lógica de programação em JavaScript
- Aplicar conceitos de services
- Trabalhar com módulos ES (ESM)
- Simular regras de negócio de um carrinho de compras
- Criar um projeto organizado para portfólio backend

---

## 🧠 Conceitos Aplicados

- Estrutura de projeto backend
- Separação de responsabilidades
- Services (camada de regra de negócio)
- Uso de import / export
- Manipulação de arrays
- Funções puras
- Padrões de nomenclatura
- Boas práticas de organização de arquivos

---

## 📁 Estrutura do Projeto

Shopee-Cart/
├── package.json
└── src/
├── services/
│ ├── cart.js
│ └── item.js
└── index.js

### Descrição das pastas e arquivos

- **package.json**  
  Contém as configurações do projeto, scripts e dependências.

- **src/**  
  Pasta principal do código-fonte.

- **services/**  
  Camada responsável pela lógica de negócio da aplicação.

  - `item.js` → Funções relacionadas à criação e manipulação de itens  
  - `cart.js` → Funções relacionadas ao carrinho de compras

- **index.js**  
  Ponto de entrada da aplicação. Responsável por orquestrar a comunicação entre os serviços.
